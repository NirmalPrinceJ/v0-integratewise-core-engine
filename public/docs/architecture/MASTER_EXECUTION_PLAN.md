## Definition of Done

- Adaptive Spine is the only canonical source of operational truth
- All MCPs operate through stable Spine contracts
- Every user surface is generated by Projection Engine from Spine metadata
- All inbound/outbound interactions pass through governed execution paths
- Adding new connectors/AI/models/targets is configuration, not architecture
