# IntegrateWise Developer & Partner Docs

Welcome to the IntegrateWise developer and partner documentation.

This site is for engineers, integration partners, and technical stakeholders who need to understand the platform well enough to build on it, integrate with it, and operate it reliably.

Not for end-user marketing.

## Where to start

- New to the platform? Start with [Getting Started](01-getting-started.md).
- Ready to build? Jump to [Quickstart](02-quickstart.md).
- Need architecture context first? Read [Platform Overview](10-architecture-overview.md) and [Runtime Topology](11-runtime-topology.md).
- Integrating externally? Read [Integration Manager](20-integration-manager.md), [Connectors](21-connectors.md), and [Capability Fabric](22-capability-fabric.md).
- Operating in production? Read [Deployment](41-deployment.md), [Observability](42-observability.md), and [Troubleshooting](50-troubleshooting.md).
