# Price Book (canonical — wins every number conflict)

A seat = one human + their Twin. The Twin is never a separate line item.

| Tier | USD seat/mo (annual) | Headline | Key gates |
| --- | --- | --- | --- |
| Starter | **$19** | See your truth | 1 workbench · 3 connectors · signals only (no Twin AI) · 4h sync |
| Growth | **$59** | Work with your Twin | 3 workbenches · 10 connectors · Twin observes/prepares/suggests · 1h sync |
| Command | **$119** | Govern the work | Unlimited workbenches · 25+ connectors · PROPOSE + governed execution + TruthLayer memory · 15min sync |
| Enterprise | Custom (15-seat min, ~$150/seat effective) | Continuity at scale | SSO/SCIM · custom policy · SLA 99.9% · DPA · dedicated support |

Monthly billing +20%. Regional (activation-gated): India ₹499/1,499/2,999 · UAE-GCC $12/39/79.

# Deal math (canonical examples)

Land 15 × Growth ≈ **$10.6K ACV** · Core 20 × Command ≈ **$28.6K** · Expanded 50 seats mixed ≈ $60–70K · Enterprise 100+ ≈ **$150K+** · Blended target ≈ $22K.

# ROI model (every proposal)

`Value/mo = H × 22 × C × A × N` — H hours/day reconstructing (default 3.0, always use the customer's), C loaded hourly (default $65), A capture 0.4/0.6/0.8 (present conservative first), N seats. Worked: 20 CSM Command seats, A=0.4 → $34,320/mo value vs $2,380 cost = **14.4x**. Payback < 1 week.

# Discount policy

Volume: 50+ seats −10% · 100+ −15% · beyond: founder approval. Design partners (2026): −50% yr 1 with logo + case-study rights, → −20% yr 2 contractually. Nonprofit/edu −30%. Multi-year: yr-2 price lock free; 2-yr prepay −10% ceiling. **Floor: never below 50% of list; never free-forever seats.** Renewal uplift cap: max(7%, CPI), 60-day notice.

# POV (not "free trial")

30 days · ≤10 seats · full Command · customer's real tools · 3 written success criteria + decision date · no auto-conversion. Success criteria menu: morning prep ≤10 min · QBR prep ≤30 min · ≥1 documented catch · ≥70% seats activated by wk 3 · security walkthrough passed.

# Packaging logic (the trust ladder)

Starter "show me the truth" → Growth "prepare things for me" → Command "act, with my approval" → Enterprise "govern it at scale." Never gated at any tier: whole-org data into the Spine, provenance/audit visibility, export, security fundamentals. We do not sell trust back at higher tiers.
