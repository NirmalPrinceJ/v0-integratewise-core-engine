# IntegrateWise Commercial OS

Status: CANONICAL · Single source of commercial truth
Owner: Founder
Created: 2026-07-21

This is the commercial operating system for IntegrateWise: 79 interconnected documents covering strategy, positioning, product marketing, sales, customer success, GTM, corporate narrative, and revenue operations. It sits beside — and never contradicts — the product doctrine (`../doctrine/`) and canonical spec (`../spec/`).

**Reading rule:** the [Terminology Guide](03-positioning-messaging/18-terminology-guide.md) wins every language conflict. The [Pricing Strategy](05-value-pricing/30-pricing-strategy.md) wins every number conflict. Newer dates win narrative conflicts; record evolutions, don't mix eras.

---

## Canon at a Glance

| Element            | Canonical value                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Category           | **Workspace for Human and AI Collaborative Work**                                                                                     |
| One-liner          | The workspace where humans and their Twins do the work together — one shared workbench, governed actions, truth the organization owns |
| Brand doctrine     | "Truth you own. AI you rent. Approval in between."                                                                                    |
| Experience promise | "My work already knows its context. AI prepared the hard parts. I decide."                                                            |
| Product stack      | Workspace → Shared Workbench → Human + Twin Collaboration → Capability Execution → Organizational Continuity                          |
| Pricing            | Per-seat: Starter $19 · Growth $59 · Command $119 /seat/mo (annual) · Enterprise custom                                               |
| Lead motion        | Enterprise/mid-market SaaS, Customer Success wedge, founder-led sales                                                                 |
| Wedge connector    | HubSpot (then Salesforce + Zendesk + Stripe)                                                                                          |
| North-star metric  | Approved Twin Actions per active seat per week                                                                                        |
| Stage (Jul 2026)   | Pre-launch → design partner program (see [77 Annual GTM Plan](13-operations/77-annual-gtm-plan.md))                                   |
