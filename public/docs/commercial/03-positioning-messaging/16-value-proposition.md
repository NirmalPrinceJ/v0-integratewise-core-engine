# 16 — Value Proposition

Status: CANONICAL · Commercial OS
Owner: Product Marketing

---

## Purpose

The value we create, stated in the customer's currency: time, risk, and compounding memory. Every ROI claim, pricing defense, and renewal conversation draws from here.

**Target audience:** Sales, marketing, CS, founders.

**Objectives:** (1) Three value streams, each quantified. (2) Persona-level value statements. (3) The value equation used consistently in every deal.

---

## 1. Master Value Proposition

> IntegrateWise returns the hours your team spends being the Human API, makes AI trustworthy enough for consequential work, and turns your organization's context into a compounding asset that survives tools, models, and turnover.

Three value streams. Every deal quantifies at least the first; great deals quantify all three.

---

## 2. Value Stream 1 — Time Returned (the wedge)

**Mechanism:** The workbench opens on assembled context (Entity360 < 200ms). The Twin prepares briefs, drafts, and analyses. The Empty Context Tax — auth again, search again, explain again, reconstruct again — stops being paid.

**Quantification (canonical numbers, keep consistent everywhere):**

| Input                             | Canonical value                                       |
| --------------------------------- | ----------------------------------------------------- |
| Context gathering today           | 2–4 hours/day per knowledge worker (use 3 for CSMs)   |
| Fully loaded hourly cost          | $65–80/hr (use $65 in team math, $80 in per-CSM math) |
| Annual waste per CSM              | ~$62,000                                              |
| Time reclaimed with IntegrateWise | 60–80% of gathering time in month one                 |
| QBR prep (design partner)         | 4 hours → 12 minutes                                  |

**The value equation (quote in every proposal — matches [Close Playbook](../../sales/close-playbook.md)):**

```
Time reclaimed/user/day × affected users × loaded hourly cost × 22 days
= Monthly team value reclaimed
```

Worked example: 2.5 hrs × 20 CSMs × $65 × 22 = **$71,500/month reclaimed**, against 20 Command seats at $119 = $2,380/month. **30x monthly return.** (See [29 ROI Framework](../05-value-pricing/29-roi-framework.md) for conservative/base/aggressive variants.)

---

## 3. Value Stream 2 — Trustworthy AI (the differentiator)

**Mechanism:** Evidence chains on every Twin intervention; TruthLayer approval on every memory write; governed proposal → approval → execution → audit on every action. The Quiet Demotion reverses: AI graduates from writing emails to doing real work — with the human still deciding.

**Quantification:**

| Value                                         | How it's counted                                                               |
| --------------------------------------------- | ------------------------------------------------------------------------------ |
| Churn signals surfaced before the score moves | churn saves attributed via signal evidence chains ($8M origin-story anchor)    |
| Missed-expansion capture                      | expansion opportunities surfaced across billing/usage/conversation per quarter |
| Risk avoided                                  | zero unapproved AI actions; zero hallucinated facts in board material          |
| AI spend consolidation                        | replaces per-app copilot seats that deliver email-drafting only                |

**Statement:** _"You already pay for AI your team doesn't trust. This is AI your team can put in front of a customer — because every claim shows its evidence and every action shows its approval."_

---

## 4. Value Stream 3 — Compounding Continuity (the moat, the renewal)

**Mechanism:** Every approved fact, decision, and outcome enters the Spine. Handovers carry full context. New hires inherit institutional memory. Model/vendor switches don't reset anything.

**Quantification:**

| Value                       | How it's counted                                                                                                                                                                                                              |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ramp time for new CSM/AE    | weeks → days (context inherited, not reconstructed)                                                                                                                                                                           |
| Handover cost               | multi-hour file assembly → transfer-ready context                                                                                                                                                                             |
| Knowledge attrition         | departing employee no longer takes the account's story with them                                                                                                                                                              |
| Continuity math (canonical) | Month 1: one week of memory replaces three status meetings · Month 3: the Twin knows patterns before the team does · Month 6: fewer duplicates, fewer surprises · Month 12: institutional memory no longer leaves with people |

**Statement:** _"Point solutions solve a moment in time. Continuity compounds. Twelve months in, the question isn't whether to renew — it's how you'd ever reconstruct what the Spine now knows."_

## 6. Value Proof Discipline

Rules for using value claims (enforced in [71 Internal Enablement](../13-operations/71-internal-enablement.md)):

- Design-partner numbers ("4 hours → 12 minutes," "89% DAU") are quoted as design-partner results until three named case studies exist ([64 Case Study Templates](../12-corporate/64-case-study-templates.md)).
- The $8M account save is the founder origin story — always told as story, never as a customer statistic.
- Every proposal includes the value equation filled with the prospect's own numbers from discovery, never generic numbers.

**KPIs:** % of proposals with customer-specific value math (target 100%); value stream 2/3 mentioned in renewal conversations (target 100%); realized-value reviews completed per customer per quarter ([75 CS Metrics](../13-operations/75-customer-success-metrics.md)).
