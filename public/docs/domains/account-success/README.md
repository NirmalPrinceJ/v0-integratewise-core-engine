## Layer 1 — Canonical Spine (Immutable Business Truth)

These are the **real-world things** the business operates on. They are append-only, versioned, tenant-scoped, and typed.

| File                      | Entity       | What it represents                  | Key attributes                                                                  |
| ------------------------- | ------------ | ----------------------------------- | ------------------------------------------------------------------------------- |
| `spine_accounts.sql`      | Account      | Paying customer relationship        | name, industry, region, tier, arr_usd, contract_start, contract_end             |
| `spine_persons.sql`       | Person       | Human being (not a CRM contact)     | name, email, role, department, seniority                                        |
| `spine_organizations.sql` | Organization | Legal entity                        | name, industry, size, type, parent_organization_id                              |
| `spine_contracts.sql`     | Contract     | Legally binding agreement           | contract_number, type, value_usd, start_date, end_date, renewal_date, status    |
| `spine_subscriptions.sql` | Subscription | Recurring billing commitment        | plan, status, mrr_usd, arr_usd, start_date, end_date, billing_frequency         |
| `spine_products.sql`      | Product      | Thing the company sells             | name, sku, category, unit_price, billing_frequency                              |
| `spine_deployments.sql`   | Deployment   | Installed product instance          | name, status, environment_type, region, product_version, last_seen_at           |
| `spine_integrations.sql`  | Integration  | System-to-system connection         | name, type, status, endpoint, protocol, version                                 |
| `spine_environments.sql`  | Environment  | Runtime boundary                    | name, type, cloud_provider, region, status                                      |
| `spine_meetings.sql`      | Meeting      | Synchronous interaction             | title, type, scheduled_at, duration_minutes, status, attendees, outcomes        |
| `spine_tasks.sql`         | Task         | Unit of work                        | title, description, status, priority, due_date, assigned_to                     |
| `spine_objectives.sql`    | Objective    | Stated goal (OKR, MBO)              | title, type, status, priority, start_date, target_date, progress                |
| `spine_initiatives.sql`   | Initiative   | Program of work                     | name, type, status, priority, start_date, target_date, progress                 |
| `spine_relationships.sql` | Edge         | Typed relationship between entities | from_canonical_id, from_type, relation_type, to_canonical_id, to_type, metadata |

### Spine rules enforced in every file:

- `id TEXT PRIMARY KEY` — assigned by pipeline, not auto-generated
- `tenant_id TEXT NOT NULL` — every record is tenant-scoped
- `canonical_id TEXT NOT NULL` — stable identity across versions
- `version INTEGER NOT NULL DEFAULT 1` — append-only versioning
- `provenance JSON NOT NULL DEFAULT '{}'` — {source, record_id}
- `created_at INTEGER`, `updated_at INTEGER` — Unix timestamps
- **No `data JSON`, no `scope JSON`, no `relationships JSON`** — typed columns only
- Relationships are stored in the **one** `spine_relationships` table

### Memory rules enforced in every file:

- `entity_type TEXT NOT NULL` + `canonical_id TEXT NOT NULL` — always links to Spine
- `confidence REAL NOT NULL DEFAULT 0.5` — every memory is opinion, not truth
- `generated_by TEXT NOT NULL` — agent/model/heuristic name + version
- `episode_id TEXT` — links to the OODA cycle that produced this memory
- `ttl_days INTEGER NOT NULL DEFAULT 7` — managed by Continuity Layer
- `valid_from INTEGER` + `valid_until INTEGER` — time-bounded; NULL = current
- `created_at INTEGER` — Unix timestamp
- Indexes on `(tenant_id, entity_type, canonical_id) WHERE valid_until IS NULL` — fast current-memory lookups
- Indexes on `(tenant_id, episode_id)` — OODA traceability
