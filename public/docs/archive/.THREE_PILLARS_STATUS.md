## Architecture Pattern

```
Frontend Component
    ↓
Imports three things:
    ├── Projection Manifest (What can I do?)
    ├── Gateway SDK (How do I talk to backend?)
    └── Design System (How do I look?)
    ↓
Component renders UI with structure, data, and styling
```

---

## Key Principles

1. **Projection Manifest** defines product experience
   - What navigation exists
   - What widgets are available
   - What commands are executable
   - What capabilities are required

2. **Gateway SDK** provides backend access
   - Only way to call backend
   - Type-safe
   - Centralized error handling
   - Authentication aware

3. **Design System** standardizes styling
   - Semantic color tokens
   - Centralized typography
   - Consistent spacing
   - Unified component patterns

## Usage Example

```typescript
import {
  CUSTOMER_SUCCESS_PROJECTION,
  getGateway,
  designSystem,
} from '@/lib'

export function CustomerDashboard() {
  const projection = CUSTOMER_SUCCESS_PROJECTION
  const gateway = getGateway()

  // Render navigation from projection
  return (
    <div className={designSystem.layout.flex.col}>
      <nav className="bg-background border-b border-border">
        {projection.navigation.map(item => (
          <a
            key={item.id}
            href={item.href}
            className={`
              px-4 py-2
              ${designSystem.interactions.hover.brighten}
              ${designSystem.interactions.transitions.normal}
            `}
          >
            {item.label}
          </a>
        ))}
      </nav>

      {/* Fetch data via Gateway SDK */}
      <useEffect(() => {
        gateway.getEntity('customer-123').then(data => {
          setCustomer(data)
        })
      }, [])

      {/* Render with Design System */}
      <main className={`p-${designSystem.spacing.scale[6]}`}>
        {/* Components here */}
      </main>
    </div>
  )
}
```
