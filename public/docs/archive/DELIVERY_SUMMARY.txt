ARCHITECTURE
─────────────────────────────────────────────────────────────────────────────

SPINE-FIRST DESIGN

The Spine is the operating state of each user:
  • 974 CANONICAL_FIELDS defined (fixed baseline)
  • Adaptive hydration (fields populate as connectors connect)
  • Single source of truth (all metrics/intelligence read from Spine)
  • Never broken (null fields show "connect tool" prompts)

Data pipeline:
  Connectors (28+)
      ↓ [Loader maps CANONICAL_FIELDS]
  Normalizer (EntityType routing)
      ↓
  SPINE (rich domain-specific rows)
      ↓ [MetricEngine computes]
  Metrics (real values, status, trends)
      ↓
  Workbenches (render with data-gap awareness)

HOW TO USE
─────────────────────────────────────────────────────────────────────────────

1. IMPORT & RENDER

  import {
    SalesRevOpsWorkbench,
    MetricEngine,
    METRICS_BY_DOMAIN,
  } from '@integratewise/domain-shells/workbenches';

  export default function SalesPage() {
    const spineRows = useSpineRows('sales_revops');
    
    const metrics = METRICS_BY_DOMAIN.sales_revops.map(metric =>
      MetricEngine.computeMetric(metric, spineRows)
    );

    const dataQuality = MetricEngine.assessDataQuality(
      'sales_revops',
      spineRows,
      CANONICAL_FIELDS
    );

    return (
      <SalesRevOpsWorkbench
        metrics={metrics}
        dataQuality={dataQuality}
        onRefresh={() => revalidate()}
        onConnectTools={() => router.push('/settings')}
      />
    );
  }

2. COMPUTE METRICS

  const metric = MetricEngine.computeMetric(
    SALES_REVOPS_METRICS[0], // M-SALES-01: Pipeline Value
    spineRows
  );

  console.log(metric);
  // {
  //   metric_id: 'M-SALES-01',
  //   value: 2500000,
  //   status: 'good',
  //   trend: { direction: 'up', percentage: 15 },
  //   confidence_score: 0.95
  // }

3. HANDLE DATA GAPS

  if (dataQuality.overall_score < 80) {
    <DataGapPrompt status={dataQuality} />
  }
