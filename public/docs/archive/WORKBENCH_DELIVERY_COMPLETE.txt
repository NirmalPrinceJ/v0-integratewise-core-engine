YOUR ARCHITECTURE
─────────────────────────────────────────────────────────────────────────────

✨ SPINE-FIRST DESIGN

The Spine is the adaptive operating state:
  • 974 CANONICAL_FIELDS across 12 domains (fixed initial state)
  • Hydrates as connectors connect (adaptive depth)
  • Never broken — null fields show prompts, not errors
  • Single source of truth for all intelligence, metrics, UI rendering

Data flow:
  Connectors (28+) → Loader (CANONICAL_FIELDS mapping)
              ↓
          Normalizer (EntityType routing)
              ↓
          SPINE (rich, domain-specific data)
              ↓
          MetricEngine (computes from Spine rows)
              ↓
          Workbenches (render metrics + data gaps)

USAGE EXAMPLES
─────────────────────────────────────────────────────────────────────────────

1. RENDER A WORKBENCH

  import { SalesRevOpsWorkbench, MetricEngine, METRICS_BY_DOMAIN } from 
    '@integratewise/domain-shells/workbenches';

  export default function SalesPage() {
    const spineRows = useSpineRows('sales_revops');
    
    const metrics = METRICS_BY_DOMAIN.sales_revops.map(metricDef =>
      MetricEngine.computeMetric(metricDef, spineRows)
    );

    const dataQuality = MetricEngine.assessDataQuality(
      'sales_revops',
      spineRows,
      CANONICAL_FIELDS
    );

    return (
      <SalesRevOpsWorkbench
        metrics={metrics}
        dataQuality={dataQuality}
        onRefresh={() => revalidateCache()}
        onConnectTools={() => router.push('/settings')}
      />
    );
  }

KEY DESIGN PRINCIPLES
─────────────────────────────────────────────────────────────────────────────

✓ Spine-First Always
  Every metric reads from Spine, never connector-specific APIs.
  Spine is the system of record.

✓ Graceful Degradation
  Null fields show "Connect [tool] to unlock [metric]" prompts.
  Never displays broken data or N/A values.

✓ Adaptive UX
  Metrics activate as Spine fields hydrate.
  System grows smarter as user connects tools.

✓ V0 Aesthetic
  Minimal design, card grids, soft colors.
  Professional typography, dark mode support.

✓ Type Safety
  Full TypeScript, no `any` types in critical paths.
  Interfaces define contract between layers.

✓ Real Thresholds
  All metrics use actual business benchmarks.
  NRR > 110 is good because that's industry standard.

✓ Reusable Components
  SpineCard, DataGapPrompt, MetricRenderer used everywhere.
  Consistent UX across all 12 workbenches.
